# Ilusion's Engine

Ilusion's Engine, o IlEn es un motor de videojuegos escrito en C++ usando un revisión moderna del lenguaje
(C++23) con el fin de crear juegos visualmente impactantes usando los recursos del sistema de manera inteligente.

El enfoque del motor es el uso apropiado de la memoria tanto de la CPU y la GPU, así como optimizar y organizar de
forma eficiente las llamadas a las GPU. Su enfoque principal son las API gráficas modernas, tales como Vulkan, Metal y
Direct X 12, aunque por compatibilidad tendrá soporte a OpenGL y Direct X antiguo (11 y puede que 10.)

Para uso exclusivo de Scardivar's Games, y a futuro ser liberado como un proyecto Open Source una vez sea estable y se
haya probado con algún lanzamiento interno.

Actualmente la lógica del motor y del juego estan mezcladas, pero en el futuro actuarán de manera separada.
